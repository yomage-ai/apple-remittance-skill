# 苹果打款材料

为苹果 App 收入准备银行收款材料。说出你想准备哪笔来款，Skill 会主动打开 Apple 后台，需要时引导你登录，然后读取数据、截图、生成形式发票和情况说明，并核对整套材料。

适合中国大陆组织开发者准备对公收款材料。

## 怎么开始

安装后，在新任务中说：

> 用苹果打款 Skill，帮我准备最近一笔苹果打款的银行收款材料。

不需要先准备文件夹、旧材料或模板，也不需要提前登录。要做某一天的来款时，在请求里加上付款日期即可。

1. Skill 打开 App Store Connect；如果尚未登录，请你在打开的 Apple 官方页面完成登录和验证。
2. Agent 查找最近一笔已付款记录，或你指定日期的来款；有多个团队或无法确定的款项时，再请你选择。
3. Agent 从后台读取公司、协议、银行和付款数据，使用内置模板生成文件，创建材料文件夹并完成核对。

已有成功样本或银行特别要求时可以补充，均为可选参考。环境检查、依赖准备、截图和文档处理由 Agent 完成；只在后台确实查不到必需资料时，才向你补问。

## 会得到什么

- 七张真实网页截图：付款报告、商务主体、公司总览、账户持有人、银行账户、登录页和 App 列表。
- 一份形式发票和一份情况说明，均为可编辑的 Word。
- 全套数据核对结果，以及仍缺少或需要确认的内容。

每张截图保留浏览器地址栏，不带标签栏和鼠标。登录页显示已填账号和密码框，密码留空。每笔款重新核对，不沿用上次金额或账号。

## 使用前了解

- 需要能访问该开发者账号及相关付款、公司和银行页面的浏览器/电脑操作工具。
- 内置中英文字段模板，支持 CNY、USD、EUR、HKD、GBP；可沿用你自己的已接受版式。公司、Apple 签约方和银行资料均取自你自己的材料。
- 这九份是参考材料组合，具体要求以收款银行为准；不保证审核通过，也不代替营业执照、协议全文或银行专用表。Apple 显示已付款不等于银行已入账。
- 个人档案、真实截图和成品保存在本地，不随 Skill 提交到共享仓库。公开包仅包含匿名模板和虚构示例。
- 不自动更改银行设置、提交材料或发送给银行。
