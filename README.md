# 苹果打款材料

为苹果 App 收入准备银行收款材料。告诉 Codex 付款日期或对应文件夹，它会访问你授权的 Apple 后台，重新截图，生成形式发票和情况说明，并核对日期、金额、主体和银行资料。

适合中国大陆组织开发者准备对公收款材料。

## 怎么开始

安装后，在新任务中说：

> 用苹果打款 Skill，帮我准备并核对 2026年2月5日 的完整材料。参考资料在这个文件夹里，浏览器已登录我的开发者账号。

首次使用时，提供已有的银行材料或银行要求即可；有已办理成功的样本更好。依赖准备、数据整理、截图、Word 生成和检查都由 Agent 完成。只有需要本人登录、验证或授权时，才需要你处理。

## 会得到什么

- 七张真实网页截图：付款报告、商务主体、公司总览、账户持有人、银行账户、登录页和 App 列表。
- 一份形式发票和一份情况说明，均为可编辑的 Word。
- 全套数据核对结果，以及仍缺少或需要确认的内容。

每张截图保留浏览器地址栏，不带标签栏和鼠标。登录页显示已填账号和密码框，密码留空。每笔款重新核对，不沿用上次金额或账号。

## 使用前了解

- 需要能访问该开发者账号及相关付款、公司和银行页面的浏览器/电脑操作工具。
- 内置中英文字段模板，支持 CNY、USD、EUR、HKD、GBP；可沿用你自己的已接受版式。公司、Apple 签约方和银行资料均取自你自己的材料。
- 这九份是参考材料组合，具体要求以收款银行为准；不保证审核通过，也不代替营业执照、协议全文或银行专用表。Apple 显示已付款不等于银行已入账。
- 个人档案、真实截图和成品保存在本地，不随 Skill 提交到共享仓库。公开包仅包含匿名模板和虚构示例。
- 不自动更改银行设置、提交材料或发送给银行。
